# Social Media Marketing Icons

Please add the following icon images to this folder:

## Required Icons (48x48px or larger, PNG format recommended)

1. **facebook.png** - Facebook logo icon
2. **instagram.png** - Instagram logo icon  
3. **youtube.png** - YouTube logo icon
4. **linkedin.png** - LinkedIn logo icon
5. **twitter.png** - Twitter/X logo icon
6. **ads.png** - Advertising/megaphone icon
7. **schedule.png** - Calendar/scheduling icon

## Icon Specifications

- **Format**: PNG with transparent background
- **Size**: 48x48px minimum (can be larger, will be scaled)
- **Style**: Flat, modern design matching the brand aesthetic
- **Colors**: Can be full color or monochrome (will be displayed on light orange background)

## Where to Get Icons

You can download official brand icons from:
- Facebook: https://about.meta.com/brand/resources/facebook/logo/
- Instagram: https://about.meta.com/brand/resources/instagram/instagram-brand/
- YouTube: https://www.youtube.com/about/brand-resources/
- LinkedIn: https://brand.linkedin.com/downloads
- Twitter/X: https://about.twitter.com/en/who-we-are/brand-toolkit

For the ads and schedule icons, you can use:
- Flaticon: https://www.flaticon.com/
- Icons8: https://icons8.com/
- Font Awesome (export as PNG)
- Heroicons: https://heroicons.com/

## Current Implementation

The icons are used in the Social Media Marketing services section with:
- 50x50px container with rounded corners
- Light orange background (rgba(255, 106, 36, 0.08))
- 8px padding inside the container
- Hover effects with border and shadow
